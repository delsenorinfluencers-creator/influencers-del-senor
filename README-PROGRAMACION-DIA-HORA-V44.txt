PROGRAMACIÓN POR DÍA Y HORA — V44

Desde el panel administrativo > Programas, crea o edita cada programa y marca los días de la semana en que se emite. Define hora de inicio y hora de fin con el selector de hora. La programación pública ordena los programas por hora y filtra según el día seleccionado.

IMPORTANTE: Ejecuta en Supabase SQL Editor el archivo supabase-programacion-panel.sql si todavía no se han creado las columnas days_of_week, start_time y end_time. La columna days_of_week usa 1=Lunes, 2=Martes, 3=Miércoles, 4=Jueves, 5=Viernes, 6=Sábado y 7=Domingo.

La programación muestra el horario publicado; no cambia automáticamente la señal de video ni inicia una transmisión. Para cambiar la señal a una hora exacta hace falta un sistema de emisión automatizada conectado al proveedor de streaming.
