# Jóvenes Influencers del Señor

Sitio web oficial de Jóvenes Influencers del Señor, medio de comunicación católico de la Diócesis de Ocaña.

## Archivos principales

- `index.html` — página principal
- `app.js` — funcionamiento y contenido dinámico
- `estilos.css` — diseño
- `supabase.sql` — estructura inicial de la base de datos

## Publicación

Este proyecto está preparado para Vercel como sitio web estático.

En Vercel selecciona:

- Framework Preset: Other
- Root Directory: `./`
- Build Command: dejar vacío
- Output Directory: dejar vacío

## Supabase

Cuando creemos el proyecto de Supabase, ejecutaremos `supabase.sql` en el SQL Editor.

Las credenciales de Supabase se configurarán posteriormente de forma segura.
