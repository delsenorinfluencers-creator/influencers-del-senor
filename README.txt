BANNER PUBLICITARIO FADE

1. Ejecuta advertising_banners.sql en Supabase.
2. Asegúrate de que tu cliente de Supabase esté disponible como window.sb.
3. Agrega publicidad.css a tu página.
4. Inserta banner-publicitario.html donde quieras mostrar el banner.
5. Las imágenes se introducen mediante image_url.
6. duration_seconds controla cuánto permanece cada imagen.
7. Las imágenes ocupan exactamente el mismo espacio.
8. La transición entre imágenes es Fade de 700 ms.
9. link_url es opcional.
