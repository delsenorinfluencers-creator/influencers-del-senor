PROGRAMACIÓN EDITABLE DESDE EL PANEL

1. En Supabase SQL Editor ejecuta: supabase-programacion-panel.sql
2. Entra al Panel administrativo > Programas.
3. Puedes crear nuevos programas o editar los existentes.
4. Cada programa permite seleccionar los días de emisión y hora de inicio/fin.
5. En En Vivo, la programación se filtra automáticamente por el día seleccionado.
6. Si no seleccionas días, el programa se mostrará todos los días.

La señal En Vivo sigue usando SSH101 y no depende de estos horarios.
