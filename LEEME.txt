# Panel completo — Jóvenes Influencers del Señor

## Sube estos archivos a GitHub

config.js
admin/panel.html
supabase-completo.sql

## Supabase

1. Authentication: crea el usuario.
2. SQL Editor: ejecuta `supabase-completo.sql`.
3. El SQL crea las tablas, RLS, bucket `media`, 11 programas y 64 registros.
4. El UUID inicial incluido es el que mostraste anteriormente. Si cambió, modifica la última sentencia INSERT del SQL.

## Vercel

Conserva:
/
  config.js
  admin/
    panel.html

La URL del panel será:

https://influencers-del-senor.vercel.app/admin/panel.html

## Storage

El panel sube imágenes al bucket público `media` y genera la URL pública automáticamente.

## Seguridad

No coloques una service_role key en el navegador. Se utiliza la Publishable Key.
