JÓVENES INFLUENCERS DEL SEÑOR - VERSIÓN MEJORADA

1. En Supabase > SQL Editor ejecuta supabase-completo.sql UNA VEZ.
2. El script crea las tablas, columnas faltantes, RLS, bucket media y los 11 programas y 64 datos.
3. El administrador inicial configurado es edinandres789@gmail.com. Si necesitas otro correo, cambia ese correo en el INSERT del SQL antes de ejecutarlo.
4. Para agregar futuros administradores: el usuario primero debe existir en Authentication > Users. Luego, desde el panel > Usuarios / administradores, agrega su UUID, correo y rol.
5. Storage: el SQL crea el bucket público media y las políticas para que los administradores puedan subir imágenes.
6. En Vivo: desde el panel selecciona m3u8, youtube, facebook, mp4 o webm. Activa Transmisión activa y las casillas Mostrar en Inicio / Mostrar en En Vivo.
7. YouTube/Facebook dependen de que el contenido sea público y de las políticas del navegador. El reproductor intenta autoplay y usa silencio para facilitar el autoplay.
8. M3U8 se reproduce con HLS.js cuando el navegador no tiene HLS nativo. MP4/WEBM se reproducen directamente.
9. Noticias: categoría, autor/editor, fecha, hora, imagen, contenido, publicación y URL amigable /iglesia-al-dia/noticia/slug.
10. Todas las páginas conservan el mismo encabezado, menú, logo, favicon y pie de página. El pie muestra centrado © año Jóvenes Influencers del Señor y Creado por Gamarra TV.
11. Si cambias el logo desde Configuración, las páginas públicas lo cargan desde site_settings; el favicon también se actualiza al logo configurado.
12. Después de subir el proyecto a Vercel, haz un despliegue nuevo y limpia la caché del navegador con Ctrl+F5.

CORRECCIÓN DE URL DE NOTICIAS
- Las noticias generan automáticamente un slug a partir del título.
- La URL pública queda /iglesia-al-dia/noticia/slug
- La página de detalle también obtiene el slug directamente de la ruta, incluso si el rewrite no pasa el parámetro query.
- Ejecuta supabase-slug-migration.sql una vez en Supabase para crear/backfillear la columna slug y el trigger.
Ejemplo:
/iglesia-al-dia/noticia/con-el-papa-en-francia-cubrimiento-especial-jovenes-influencers-del-senor-iglesia-al-dia
